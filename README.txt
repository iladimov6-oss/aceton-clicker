1. Создайте публичный репозиторий GitHub с именем aceton-clicker.
2. Загрузите в корень все файлы из этого архива (не сам архив).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Откройте https://ВАШ-ЛОГИН.github.io/aceton-clicker/ в Safari.
5. Поделиться > На экран Домой > Добавить.
Примечание: данные из старого локального HTML не переносятся автоматически.
